# Oyun detay sayfası görseli

Oyunlar > Düzenle içinde üç görsel birbirinden ayrıdır:

- Oyun Kartı Görseli: Ana sayfadaki dikey kart (3:4, 900×1200).
- Oyun Detay Sayfası Görseli: Kart tıklanınca açılan sayfanın üst kısmındaki yatay görsel (16:9, 1920×1080).
- Oyun Logosu: Detay sayfasında gösterilen şeffaf logo.

Ana sayfanın Banner Yönetimi ise tamamen bağımsızdır.

Foodie Match Travel için eskiden yüklenen yatay banner, mevcut görüntü kaybolmaması için detay görseli alanına aktarılmıştır. Yeni bir görsel yükleyebilir veya bu alanı boşaltabilirsin. Boş bırakıldığında dikey oyun kartı resmi asla detay sayfasının arka planına taşınmaz; koyu arka plan gösterilir.

Yayın öncesi `Siteyi Gör` ile kontrol edip GitHub ZIP dışa aktarma yap.
