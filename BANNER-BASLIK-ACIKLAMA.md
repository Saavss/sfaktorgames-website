# Banner alanları

Admin panelinde **Oyunlar > Düzenle** bölümüne girin.

- **Banner Başlığı / Banner Heading**: Logonun altında görünen, yedi dilde ayrı düzenlenen slogan/başlık.
- **Banner Açıklaması / Banner Description**: Yalnızca banner içinde görünen, oyun kısa açıklamasından bağımsız metin. Yedi dilde ayrı yazılabilir.
- Banner açıklaması boş bırakılırsa geçmiş kayıtlarla uyumluluk için o dilin **Kısa Açıklama** alanı kullanılır.
- Banner başlığı boş bırakılırsa oyun adı kullanılır.
- Logo daha büyük gösterilir, mobil cihazda otomatik ölçeklenir.

Değişiklikleri kaydedin; önizlemede ve GitHub ZIP paketinde aynı veriler kullanılır.
