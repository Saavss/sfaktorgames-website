# Oyun İçerikleri — 7 Dil

Admin panelinde Oyunlar > Düzenle altında Türkçe, English, Deutsch, 한국어, Português, 简体中文, 繁體中文 için oyun adı, banner sloganı, kısa açıklama ve uzun açıklama alanları vardır.

Yeni dilleri kendiniz doldurabilirsiniz. Otomatik çeviri yapılmaz; boş alanlarda İngilizce, ardından Türkçe varsayılan içerik kullanılır.

Oyuna özel gizlilik politikası yalnızca İngilizcedir ve diğer oyun metinlerinden ayrıdır. Genel web sitesi gizlilik sayfası da ayrı kalır.

Yeni bir oyun alanını doldurduktan sonra Kaydet düğmesine basın, GitHub ZIP dosyasını yeniden dışa aktarın. Site ziyaretçileri için yerel admin paneline ihtiyaç yoktur.
